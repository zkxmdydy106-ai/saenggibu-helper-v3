# EVAL_CHECKLIST.md — 생기부 품질 평가 기준

생성물 1건을 평가할 때의 채점표. 회귀 테스트(REGRESSION_TESTS.md)와 함께 사용.

## A. 형식 (Pass/Fail — 하나라도 Fail이면 재작성)
- [ ] 음슴체(`~함/~음/~임`) 일관 종결
- [ ] 영역 글자수 상한 이내 (과세특/자율 500자, 진로 700자)
- [ ] 금지사항 0건
- [ ] 본문 내 학생 이름·학교 식별정보 없음
- [ ] 비유·현학 표현 0건 + 지어낸 감정·의욕 서술 0건 (format_guard 문체 경고 없음)
- [ ] 수식·기호 0건 (format_guard 차단 항목)
- [ ] 역량 이름 명시 0건 (format_guard 경고 없음)

## B. 내용 (5점 척도, 4점 이상 권장)
| 항목 | 1점 | 3점 | 5점 |
|---|---|---|---|
| 사고 중심성 | 활동만 나열 | 일부 사고 언급 | 통념·궁금증→절차→적용·확장 서사 완결 |
| 구체성 | 추상어 위주 | 일부 구체 사례 | 실제 절차·수치로 뒷받침(수식은 말로) |
| 연결·심화 | 단편적 | 개념 일부 연결 | 교과/타 영역과 깊은 연결 |
| 주도성 표현 | 수동적 | 보통 | 학생 행위로 주도성 입증 |
| 담백함(문체) | 비유·현학·지어낸 감정 다수 | 일부 꾸밈 | 비유 없이 담담한 사실 서술, 장면·사실로 맺음 |
| 수업 장면성 | 보고서 요약·역량 선언 | 장면 1개 | 의문 지점·질문·피드백 반영·발표 등 장면으로 학업역량이 드러남 |
| 진정성 | 과장·상투 | 무난 | 실제 관찰 기반, 차별화 |

## C. 평가 자동화
```
python ../hooks/format_guard.py --area 과세특 --file 결과.txt
```
종료코드 0이고 문체 경고가 없으면 A 항목 자동 통과. B 항목은 사람이 채점.
