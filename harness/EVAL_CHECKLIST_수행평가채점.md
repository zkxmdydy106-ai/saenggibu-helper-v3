# EVAL_CHECKLIST.md — 수행평가 채점 품질 평가 기준

채점 결과 1건(과제 단위)을 평가하는 채점표. REGRESSION_TESTS.md와 함께 사용.

## A. 형식·규칙 (Pass/Fail — 하나라도 Fail이면 재채점)
- [ ] 채점기준표를 실제로 확보·구조화했다 (없이 채점하지 않았다)
- [ ] 모든 요소 점수 ≤ 만점, 음수 없음
- [ ] 총점 = 요소 점수 가중 합, 기준표 총점 이내 (산술 오류 0)
- [ ] 대상 학생 전수 처리, 미제출·확인필요 명시
- [ ] 모든 점수에 제출물 기반 근거 존재
- [ ] 엑셀 3개 시트 생성(채점결과·근거피드백·요약통계), 요소·만점 반영

자동 점검:
```bash
python ../hooks/grading_guard.py --file grades.json
python ../skills/assessment-grader/scripts/build_scoresheet.py grades.json -o out.xlsx
```

## B. 내용 (5점 척도, 4점 이상 권장)
| 항목 | 1점 | 3점 | 5점 |
|---|---|---|---|
| 기준 충실성 | 기준 무시·인상 채점 | 기준 일부 반영 | 모든 점수가 수준 기술에 정확 대응 |
| 근거 구체성 | 근거 없음/추상 | 일부 구체 | 제출물 인용·요약으로 명확 |
| 피드백 균형 | 비난/공허 | 강점 또는 보완만 | 강점+보완+실행 제안, 존중 톤 |
| 일관성 | 유사 답 점수 들쭉 | 대체로 일관 | 동일 수준=동일 점수, 모순 없음 |
| 공정성 | 무관 요소 영향 | 대체로 중립 | 무관 요소 완전 배제, 개인정보 미노출 |

## C. 합격 기준
- A 전부 Pass + B 평균 4.0 이상 → 사용 가능(교사 검토용 초안)
- A Fail → 무조건 재채점
- B 3점대 → 근거·피드백 보강 후 재산출
