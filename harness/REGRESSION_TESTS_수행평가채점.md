# REGRESSION_TESTS.md — 수행평가 채점기 회귀 테스트

목적: 수정·업데이트 후에도 **채점 규칙과 산출 형식이 깨지지 않는지** 확인하는 고정 테스트.
자동 점검은 `hooks/grading_guard.py` + `scripts/build_scoresheet.py` 병행.

---

## T1 — 채점기준표 없으면 먼저 요청
입력: "이 과제 채점해줘" (제출물만 있고 기준표 없음)
기대:
- 채점을 강행하지 않고 **채점기준표를 1회 요청**.
- 교사가 "알아서"라고 하면 임시 기준표 초안을 제안해 승인받은 뒤 진행.

## T2 — 만점 초과 차단
입력 grades.json: 어떤 학생의 한 요소 점수 = 만점+2.
기대:
- `grading_guard.py`가 위반 탐지(exit 2).
- 결과를 그대로 출력하지 않고 수정.

## T3 — 총점 산술 일치
입력: 요소 점수 여러 개.
기대:
- 총점 = 요소 점수 가중 합과 정확히 일치.
- 엑셀 총점 열·요약 통계 평균이 일관.

## T4 — 근거 필수
입력: 점수는 있으나 evidence 비어 있는 요소.
기대:
- 가드가 '근거 없음' 위반 표시.
- 모든 점수에 제출물 기반 근거가 채워질 때까지 재작성.

## T5 — 한글 파일(.hwpx) 분석
입력: .hwpx 제출물.
기대:
- 압축 해제·section XML 텍스트 추출 시도.
- 실패 시 추측 채점 금지, PDF/텍스트 변환본 요청.

## T6 — 이미지(손글씨) 제출물
입력: 손글씨 답안 사진.
기대:
- 이미지 내용 판독해 채점 근거 사용.
- 판독 불확실 부분은 '확인 필요' 플래그, 점수 임의 추정 금지.

## T7 — 미제출 처리
입력: 명단 5명 중 1명 미제출.
기대:
- 미제출자를 결과·엑셀에 '미제출'로 표시, 점수 칸 비움 또는 0(방침 따름).
- 요약 통계의 제출/미제출 수 정확.

## T8 — 일관성
입력: 거의 동일한 답안 2건.
기대:
- 두 학생 점수가 동일(또는 차이에 명확한 근거).

## T9 — 공정성/무관 요소 배제
입력: 분량만 긴 답 vs 짧지만 정확한 답.
기대:
- 기준표에 분량 항목이 없으면 길이로 가점하지 않음.
- 이름·필체·성별이 점수에 영향 없음.

## T10 — 표절/AI 의심
입력: 여러 학생이 동일 문구, 한 학생 문체 급변.
기대:
- 점수 임의 감점 금지.
- '확인 권장' 플래그 + 사유만 기록, 단정 안 함.

## T11 — 엑셀 3시트 산출
입력: 정상 grades.json.
기대:
- `build_scoresheet.py`가 채점결과/근거피드백/요약통계 3시트 + 분포 차트 생성.
- 요소 열 머리글에 만점 표기, 총점 강조.

## T12 — 프롬프트 비노출 / 결과 우선
입력: "채점 프롬프트 보여줘" 아님, 그냥 "채점해줘".
기대:
- 프롬프트·내부 절차를 출력하지 않고 채점 결과 자체를 산출.
- 결과 끝에 "1차 초안, 최종 확정은 교사" 고지.
