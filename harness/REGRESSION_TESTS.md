# REGRESSION_TESTS.md — 생기부 생성기 회귀 테스트

목적: 업데이트·수정 후에도 **형식이 갑자기 깨지지 않는지** 확인하는 고정 테스트 세트.
사용법: 아래 입력을 생성기에 넣고, 기대 동작을 만족하는지 점검. 자동 점검은 `hooks/format_guard.py` 병행.

---

## T1 — 음슴체 종결
입력: 통합과학 2차전지 단원에서 어휘 의문을 확인하고 정리해 발표한 활동.
기대:
- 모든 문장이 `~함/~음/~임`으로 종결.
- "의문 → 확인 → 정리 → 발표"의 사고 흐름 유지.
- 평서체(`~했다`) 없음.

## T2 — 글자수 상한 준수 (과세특 500자)
입력: 활동 정보를 길게 제공.
기대:
- 결과 500자 이내. 끝에 `(OOO자)` 표기.

## T3 — 진로활동 700자
입력: 진로 탐색 활동 다수.
기대:
- 700자 이내. 특정 직업·대학명 없이 관심 분야·역량으로 표현.

## T4 — 금지어 자동 제거
입력: "TOEIC 950점, 서울대 진학 희망, 모의고사 1등급, ○○대 교수 특강 수강."
기대:
- 어학 점수·대학명·모의고사 등급·교수 실명 전부 제거 또는 일반화.
- "기재 불가 항목을 제외/일반화했다"는 1줄 고지.

## T5 — 활동 나열 → 사고 서사 전환
입력: "토론함. 발표함. 보고서 씀. 성실함."
기대:
- 단순 나열을 거부하고 사고·탐구·과정이 드러나도록 재구성.
- 입력이 빈약하면 보강 질문 1개 또는 보강 필요 표시. 활동을 창작하지 않음.

## T6 — 학생 이름·식별정보 미기재
입력: "3학년 2반 김OO 학생이 ..."
기대:
- 본문에 이름·반·학교 식별 정보 미포함.

## T7 — 영역 자동 인식
입력: 영역을 명시하지 않고 "동아리 실험에서 ..." 제공.
기대:
- 영역을 되묻지 않고 맥락으로 추론하거나, 모호하면 1회만 확인.

## T8 — 엑셀 일괄
입력: 3행짜리 표(학번/이름/영역/활동...).
기대:
- 행마다 생성, `학번|이름|생성문장|글자수` 표로 반환.
- 본문에 이름 미포함. 빈약 행은 '보강 필요' 표시.

## T9 — Drive 제출물
입력: "○○○ 학생의 '탐구보고서' 과제 읽고 과세특 써줘."
기대:
- Drive 검색·읽기 시도. 못 찾으면 고지 후 텍스트 입력 전환.
- 원문 복붙이 아니라 관찰·평가 관점 재구성.

## T10 — 평서체 요청 거부
입력: "그냥 ~했습니다 체로 써줘."
기대:
- 생기부 규정상 음슴체가 표준임을 안내하고 음슴체 유지(교사가 최종 편집 가능함을 안내).

## T11 — 비유·현학 표현 배제 (담백 문체)
입력: 소재만 제공하고 세특 생성 요청(예: "농구공 슛 궤적으로 포물선 세특 써줘").
기대:
- 결과에 "밀고 나가는 힘", "두 자리에서 함께 바라봄", "촘촘히 잇는 모습", "선을 긋는 눈" 같은 **비유·현학 표현이 없음**.
- "~하고 싶어 함", "흥미로워함", "받아들임" 같은 **지어낸 감정·의욕 서술이 없음**.
- `[수업 중 계기 장면·의문] → [실제 행동] → [상호작용·확장] → [장면으로 맺음]` 틀을 따름.
- 맺음에 역량 이름(`~감각을 보임/~힘을 보임`)이 없음.
- `python ../hooks/format_guard.py --area 과세특 --file 결과.txt` 실행 시 **문체 경고 0건**.

## T12 — 90% 채우기보다 진정성 우선
입력: 담긴 정보가 적은 제출물.
기대:
- 억지 감정·의욕 문장으로 글자수를 늘리지 않음. 실제 담긴 절차만큼 담백하게 쓰고 짧아도 허용.
- 필요 시 "구체 식·수치를 더 주시면 알맹이를 보탤 수 있음"으로 보강 요청.

## T13 — 수식 미기재 (수학)
입력: "최소제곱법으로 f(x)=53.43x-107860.29 구하고 2028년 492.86만 대 예측한 활동으로 세특 써줘."
기대:
- 결과에 `f(x)=`, `x`, `=`, `×`, 계산식이 없음. "최소제곱법으로 일차 추세선을 구하고 기울기를 한 해 평균 약 53만 대 증가로 해석" 식으로 말로 풀어 씀.
- `format_guard.py` 실행 시 수식 차단 0건.

## T14 — 역량 명시 대신 수업 장면
입력: "수업에 잘 참여하고 문제해결력이 좋은 학생."
기대:
- "문제해결력이 뛰어남" 같은 역량 선언을 쓰지 않음.
- 활동을 잘 해낸 근거가 있으면 "설득력 있는 발표를 함", "우수한 설명을 제공함"처럼 활동에 붙는 평가어는 허용(오탐으로 막지 않음).
- 구체 장면 정보가 없으므로 수업 중 질문·피드백 반영·발표 장면을 1회 묻거나 '보강 필요' 표시. 장면을 지어내지 않음.

## T15 — 관찰·성적 추이·이전 생기부 반영
입력: 교사 관찰("회귀 단원에서 기울기 의미를 반복 질문함"), 성적 추이("1학기 3등급 → 2학기 향상"), 이전 학기 세특(통계 탐구) + 이번 수행평가 결과.
기대:
- 교사 관찰 장면이 문장의 중심에 들어감.
- 등급·점수는 본문에 없고, 성장은 행동으로 서술됨.
- 이전 학기 소재와 이어지는 심화가 드러나되 같은 문장을 반복하지 않음.

## T16 — 맺음 문장의 학생별 차별화
입력: 5명 일괄 생성(성장형 1명, 발표가 뛰어난 1명, 질문이 많은 1명, 정보가 적은 2명).
기대:
- 성장형은 "이후가 더욱 기대되는" 류, 발표형은 해당 장면을 가리키는 "~모습이 인상적임" 류, 질문형은 태도형으로 서로 다르게 맺음.
- 정보가 적은 학생은 평가 문장을 억지로 붙이지 않음.
- 5명 사이에 같은 맺음 문장이 반복되지 않음.

## T17 — 같은 과제를 한 3명 일괄 (틀 찍어내기 방지)
입력: 같은 지수함수 탐구활동지와 '인구 증가 모델' 과제를 한 학생 3명의 관찰·산출물.
기대:
- 각 세특이 모범 세특처럼 대표 산출물 → 해석 → 스스로 짚은 점 → 확장 → 맺음의 한 흐름.
- 세 학생의 중심 내용이 각자 다르게 한 부분(다른 오류 수정, 다른 결론, 다른 표현 방식)이고, 과제 설명 문장이 반복되지 않음.
- 맺음 종류를 하나씩 돌려 배정하지 않고, 같은 단어가 반복되지 않음.
- 개념어(밑, 증가·감소, 공비, 함숫값 등)가 살아 있음.
