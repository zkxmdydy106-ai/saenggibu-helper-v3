# USAGE_EXAMPLES.md — 수행평가 채점기 사용 예시

핵심: **기준표 먼저 → 증거 기반 채점 → 근거·피드백 → 엑셀 3시트.**

---

## 예시 A — Google Classroom 과제 일괄 채점

교사:
> 3학년 2반 '국어' 수업의 '독서 감상문' 과제 채점해줘.

도구:
> 채점기준표(루브릭)를 주세요. 파일 업로드 / Classroom·Drive 위치 / 텍스트 붙여넣기 중 편한 방식이면 됩니다.

교사: (루브릭 엑셀 업로드 — 내용8·논리7·표현5, 총 20점)

도구:
1. Classroom에서 '독서 감상문' 제출물 28건 + 미제출 2명 수집.
2. 각 제출물(문서/이미지) 분석 → 요소별 증거 추출.
3. 학생별 채점 → 근거·피드백 작성 → 가드 검증.
4. 채팅에 요약 표 제시 + 엑셀 생성:
```
[과제] 독서 감상문 | [기준표] 요소 3개 / 총점 20점
[대상] 30명 (제출 28 · 미제출 2 · 확인필요 1)

이름  내용/8  논리/7  표현/5  총점/20  코멘트
김OO    7      5       4      16    근거 제시 좋음, 결론 보완 필요
…
✅ 기준표 적용 / 만점·합계 OK / 근거·피드백 포함 / 공정성 확인
📊 수행평가_채점결과_독서감상문_20260625.xlsx (3시트)
※ 1차 초안입니다. 최종 확정은 선생님 검토가 필요합니다.
```

## 예시 B — Classroom 밖, 직접 업로드 (이미지·한글·PPT 혼합)

교사:
> (사진 5장 + .hwpx 3개 + 발표 .pptx 2개 업로드) 이거 수행평가 채점해줘. 기준표도 첨부했어.

도구:
- 이미지=손글씨 답안 판독, .hwpx=압축 해제 후 텍스트 추출, .pptx=슬라이드 추출.
- 파일명/표지에서 학생 매핑(모호하면 1회 확인).
- 첨부 기준표로 채점 → 엑셀 산출.
- 판독 불가했던 사진 1장은 '확인 필요'로 표시하고 점수 보류.

## 예시 C — 기준표가 서술형뿐 (가정 1줄)

교사: (배점만 있고 수준 기술 없는 기준표)
도구:
> 상/중/하 구간을 균등 배분으로 가정해 채점했습니다(예: 내용 8점 → 상 7-8/중 4-6/하 0-3). 다른 구간을 원하시면 알려주세요.
→ 가정 명시 후 진행.

## 예시 D — 표절 의심 (단정 금지)

상황: 3명이 동일 문단.
도구:
- 점수를 임의로 깎지 않음.
- 엑셀 '확인필요' 열에 `표절 확인 권장: 동일 문단(○○와 유사)` 플래그만 기록.

## 직접 도구 사용 (파이프라인)

```bash
# 1) 채점 결과를 grades.json으로 정리(스키마: references/excel-output.md)
# 2) 규칙 검증
python 수행평가채점기/hooks/grading_guard.py --file grades.json
# 3) 엑셀 생성
python 수행평가채점기/skills/assessment-grader/scripts/build_scoresheet.py grades.json \
  -o 수행평가_채점결과_독서감상문_20260625.xlsx
```
같은 grades.json으로 **검증 → 엑셀**이 이어진다.
