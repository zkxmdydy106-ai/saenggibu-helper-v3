# HOOK — 생기부 형식 가드 (Format Guard)

> 목적: 생성된 생기부 문장이 **음슴체·글자수·금지사항** 기준에서 벗어나지 않도록 **결정적으로(deterministic)** 잡아준다.
> 일반 지침만으로는 가끔 평서체로 새거나 글자수를 넘기는 일이 생기므로, hook으로 마지막 안전망을 둔다.
>
> - **Claude 웹/앱 Project**: hook 실행은 불가하므로, 이 문서를 Project Knowledge로 올려 두고 `프로젝트지침.md §7 품질 점검`이 매 출력 전 자가검증을 수행하게 한다. (사실상 같은 효과)
> - **Claude Code repo**: 아래 `settings.json` 스니펫과 `format_guard.py`로 실제 hook을 건다.

## 가드가 검사하는 3가지
1. **음슴체**: 문장 종결이 `~함/~음/~임/~보임/~돋보임` 등인가? `~했다/합니다/입니다/이다/된다`가 있으면 경고.
2. **글자수**: 영역 상한(과세특 500·진로 700·자율 500자) 초과 시 경고.
3. **금지어**: 공인어학시험명, 모의고사/석차/등급, 논문·특허·출간, 대학명 패턴, 부모 직업 등 키워드 탐지 시 경고.
4. **문체 주의어(비차단 경고)**: 비유·현학 표현("밀고 나가", "함께 바라", "촘촘히 잇", "선을 긋는", "두 자리에서" 등)과 지어낸 감정·의욕 서술("하고 싶어 함", "흥미로워함", "받아들임", "마음을 품" 등)을 탐지하면 **경고만** 하고 종료코드는 바꾸지 않음. 이 경고가 뜨면 비유를 걷어내고 구체 절차·수치로 담백하게 고쳐 씀.

## 동작 방식 (권장: 경고형, 비차단)
형식 위반을 발견하면 **차단(block)하기보다 경고 메시지로 되돌려** Claude가 스스로 고쳐 다시 내보내게 한다. 교육 현장 도구이므로 과도한 차단은 오히려 방해가 된다.

## Claude Code settings.json 스니펫
`.claude/settings.json` 에 병합:

```json
{
  "hooks": {
    "SessionStart": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": "printf '%s\\n' '생기부 작성 모드: 모든 문장은 음슴체(~함/~음/~임)로 종결. 글자수 상한(과세특500·진로700·자율500자) 준수. 금지사항(교외수상·어학성적·논문·특허·대학명·부모정보 등) 기재 금지. 활동 나열이 아닌 사고·탐구·성장 서사로 작성.'"
          }
        ]
      }
    ],
    "Stop": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": "python .claude/hooks/format_guard.py"
          }
        ]
      }
    ]
  }
}
```

> `Stop` 이벤트가 없는 환경이면 `PostToolUse`(Write/Edit 매처)로 대체해 생성 파일을 검사하게 할 수 있다.

## 검증 스크립트
- `format_guard.py` — 표준입력 또는 파일 경로로 받은 생기부 텍스트를 검사하고, 위반 시 `{"decision":"block","reason":...}` 형태로 사유를 돌려준다.
- 단독 실행으로 글자수·음슴체·금지어 점검 도구로도 쓸 수 있다:
  `python format_guard.py --area 과세특 < 결과.txt`
