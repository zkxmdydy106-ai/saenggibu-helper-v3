# 생기부 작성 스킬 (saenggibu-writer)

학생 활동·사고·태도 정보를 **교육부 기재요령에 맞는 생기부 문장**으로 변환한다.
핵심 철학: **활동 나열이 아니라 사고·탐구·성장의 서사.**

## 언제 쓰나
- 교과세특(과세특), 진로활동, 자율·자치활동 특기사항을 새로 쓸 때
- 기존 초안을 음슴체/글자수/금지사항 기준으로 다듬을 때
- 여러 학생을 표로 일괄 생성할 때

## 작성 절차
1. **영역 확정** — 교과세특 / 진로활동 / 자율·자치활동 중 무엇인지 확인.
2. **원자료 확보** — 텍스트 메모, Drive 제출물, 엑셀 행 중 하나 이상. 아래 자료가 **들어와 있으면 모두 참고**한다(없으면 있는 것만으로 쓴다). 학생을 한 명씩 본 관찰이 많이 들어갈수록 좋은 생기부가 된다.
   | 자료 | 활용 방법 | 주의 |
   |---|---|---|
   | ① 교사 관찰 기록 | **가장 우선.** 수업 중 장면(질문, 막힌 지점, 피드백 반영, 발표, 또래 도움)을 그대로 문장의 뼈대로 삼음 | 관찰에 없는 장면은 만들지 않음 |
   | ② 학생 활동·산출물 | 수행평가 결과물, 보고서·발표 제목, 사용한 자료명, 결과 수치 | 산출물 문구를 그대로 옮기지 않고, 학생이 실제로 한 행동만 뽑음 |
   | ③ 과거 성적 추이 | 성장 서사의 **배경으로만** 사용(예: 초반에 어려워하던 단원을 질문과 반복으로 따라잡은 과정) | 점수·등급·석차·평균 같은 성적 수치는 **본문에 절대 쓰지 않음** |
   | ④ 이전 학기·학년 생기부 | 관심 주제의 이어짐과 심화를 보여줌(예: 1학기 통계 탐구 → 2학기 회귀 모델), 같은 문장·소재가 반복되지 않게 확인 | 이전 문장을 복사하지 않음. 이어지는 흐름은 은근히 드러냄 |
   영역별 비중: **교과세특**은 ①②(수업 장면과 교과 개념) 중심에 ③④는 성장·심화를 보여줄 때만. **진로활동**은 ②④로 관심이 이어지고 좁혀지는 흐름을 중심으로. **자율·자치활동**은 ①(역할, 갈등 조정, 책임감 장면) 중심으로.
   - **수업 장면 확인**: 제출물만 있고 수업 중 장면 정보가 없으면 교사에게 짧게 묻는다 — ① 수업 중 한 질문이나 막힌 지점 ② 교사 피드백 뒤 달라진 점 ③ 발표·모둠·또래 설명 장면. 답이 없으면 제출물에서 확인되는 행동만으로 쓰고, 지어내지 않는다.
3. **사고 흐름 추출** — 입력에서 다음을 찾아낸다:
   - 학생이 가진 **질문·의문·문제의식**
   - **탐구·해결 과정**(자료 활용, 개념 연결, 실험·분석)
   - **결과물·발표·산출물**(실제 보고서·발표 제목, 사용한 도구·자료명, 수치)
   - 사고를 **확장·심화**한 지점(다른 맥락·이론과 연결, 더 알아본 것)
   - 태도·역할·변화
   ※ '한계·부족·아쉬움'을 굳이 지적하지 않는다. 확장은 결핍이 아니라 관심·호기심으로 서술.
4. **음슴체 서술** — 위 흐름을 한 편의 짧은 서사로. 종결은 음슴체를 유지하되 `~함`만 반복하지 말고 `~됨/~보임/~드러남/~밝힘/~봄` 등을 섞어 리듬을 만든다.
5. **규칙 적용** — 글자수 상한, 금지사항, 이름·식별정보 제거.
6. **자가 점검** — `references/checklist.md` 통과 후 글자수 표기와 함께 제시.

## 영역별 글자수 상한 (한글, 공백 포함)
- 교과세특: 과목당 **500자** (공통과목1·2는 합산 500자)
- 진로활동: **700자**
- 자율·자치활동: **500자**
- 동아리활동: **500자** (참고)

상한 초과 금지. 90% 안팎이 좋지만 글자수를 채우려고 장면을 더 넣지 않는다. 끝에 `(OOO자)` 표기.

## 좋은 문장의 특징 (반드시 반영)
- **구체적 행동·근거**가 있다. ("적극적으로 참여함" 같은 공허한 표현 지양)
- **인과·과정**이 보인다. (의문 → 탐구 → 자료 → 재구성 → 확장)
- **개념 연결·심화**가 드러난다. (배운 내용을 다른 맥락·이론과 연결)
- **주도성·비판적 사고**가 학생의 행위로 표현된다.
- 교사의 **관찰·평가** 관점이다. (학생이 제출한 문구를 그대로 옮기지 않음)

## 사람이 쓴 것처럼 (AI 티 제거) — 매우 중요
실제 교사가 쓴 우수 세특과 AI 문장의 진짜 차이는 문체가 아니라 **구체적 알맹이의 밀도**다. 아래를 지킨다.

1. **고유명사·실제 제목을 넣는다.** 보고서·발표 제목은 따옴표로(예: '정적분이 심장을 뛰게 만든다'), 사용한 개념·이론·물질·도구·자료 출처는 실제 이름으로. 이 알맹이가 없으면 아무리 다듬어도 AI 티가 남는다. **모르면 지어내지 말고, 교사에게 실제 제목·자료명을 물어 채운다.**
2. **'상식 → 개념'의 2단 전개.** 학생이 아는 상식·통념을 먼저 깔고, 그것을 교과 개념으로 끌어올린 지점을 보여준다. (예: '점수 높으면 붙는다'는 통념 → 확률로 검증)
3. **묘사 먼저, 평가 나중.** "인상적임/돋보임" 같은 평가어 자체는 사람도 쓴다. 단, 구체적 행동을 충분히 서술한 **뒤에** 붙인다. 평가어가 근거 없이 문장 끝에 붕 뜨면 안 된다.
4. **종결어미를 섞고, 너무 매끈하게 다듬지 않는다.** 모든 문장을 똑같은 길이·`~함`으로 맞추면 기계 같다. 문장 길이에 강약을 주고 종결을 다양화한다.
5. **정형 마무리 금지.** "후속 탐구를 계획함", "후속 과제를 남김", "~할 것으로 보임" 같은 템플릿 맺음말을 쓰지 않는다. 학생의 구체적 다짐·깨달음·다음 관심으로 자연스럽게 맺는다.
6. **부정·한계 지적을 넣지 않는다.** "~하지 못한 점이 아쉬움", "~을 더 다듬으면 좋겠음" 같은 결핍 서술 금지. 확장은 호기심으로 긍정 서술.
7. **비유·현학·잘 안 쓰는 표현을 쓰지 않는다 — 담백하게.** 교사는 "개념을 낯선 맥락으로 밀고 나가는 힘", "두 자리에서 함께 바라봄", "식과 현실을 촘촘히 잇는 모습", "선을 긋는 균형 잡힌 눈", "스스로 의미를 세우는 태도" 같은 문학적·은유적 표현을 쓰지 않음. 실제로 무엇을 했는지를 **구체 절차·수치**로 담담히 적고, 감정·의욕을 지어 붙이지 않음("~하고 싶어 함", "흥미로워함", "또렷하게 받아들임" 금지). 맺음은 은유가 아니라 **구체 장면이나 사실**로 끝낸다. 교사 판단이 꼭 필요하면 태도·변화를 관찰한 한 문장만 붙이고, 역량 이름은 쓰지 않는다(8번).
8. **역량을 이름으로 쓰지 않고 수업 장면으로 보여준다.** "문제해결력", "수학적 사고력", "탐구역량", "~하는 힘을 보임", "~감각을 보임", "~능력을 보임" 같은 역량 명시는 자제한다. 대신 수업 중 **언제·무엇을 보고·어떻게 했는지**를 장면으로 쓴다. (예: "문장 구조를 이해하기 어려워 틈틈이 교사에게 질문하고, 받은 피드백으로 해당 부분을 다시 풀어봄") 교사 판단은 성장·태도처럼 장면만으로 드러나기 어려운 경우에만 한 문장으로 개입한다.
   - **허용: 활동·산출물을 꾸미는 평가어.** 활동을 잘 해낸 경우 "설득력 있는 비평을 전달함", "우수한 보충 설명을 제공함", "짜임새 있는 발표를 함"처럼 구체 활동 앞에 붙는 평가어는 써도 된다. 막는 것은 학생 자체에 붙는 역량 이름·총평("문제해결력이 뛰어남", "우수한 학생임")이다.
9. **학업역량이 장면 속에서 자연스럽게 드러나게 한다.** 역량을 선언하지 말고 행동으로 보여준다. 기본 구성은 `프로젝트지침_생기부.md` 1-2장의 틀(대표 산출물 1개 + 확장 1개)을 따르고, 아래 작은 장면 요소는 흐름을 뒷받침할 때만 **0~2개** 넣는다(모두 채우지 않는다). 교과 개념어는 정확히 살려 쓴다.
   - 학업태도: 모르는 부분을 그냥 넘기지 않고 질문한 장면, 피드백을 받아 고친 과정, 꾸준히 반복한 기록
   - 탐구력: 수업 자료·문장·자료값에서 의문이 생긴 구체 지점 → 스스로 확인한 자료·방법 → 알게 된 사실
   - 학업성취: 개념을 정확히 쓴 흔적(무엇을 구했고 그 값이 무엇을 뜻하는지 말로 해석), 또래에게 설명·보충한 장면
   - 변화: 처음 어려웠던 점 → 활동 뒤 달라진 점(교사가 실제 관찰한 경우만)
10. **수식을 그대로 쓰지 않는다 (수학·과학).** `f(x)=ax+b`, `y=-0.2(x-3)²+3.8`, `∑`, `√`, 분수식, 계산식 같은 수식·기호는 쓰지 않고 **말로 풀어** 쓴다. (❌ "f(x)=53.43x-107860.29를 구함" → ✅ "최소제곱법으로 일차 추세선을 구하고, 기울기를 한 해 평균 약 53만 대씩 늘어나는 속도로 해석함") 의미가 있는 결과 수치(예측값, 비율)는 단위와 함께 짧게 쓸 수 있다.

11. **교사 맺음 문장은 허용하되, 학생마다 상황에 맞게 다르게 쓴다.** "~하는 모습이 인상적임", "앞으로의 성장이 더욱 기대되는 학생임" 같은 교사 평가·기대 문장을 쓸 수 있다. 단, **모든 학생에게 같은 문장을 붙이지 않는다.**
   - **근거에 맞춰 고른다**: 눈에 띄는 한 장면이 있으면 → 그 장면을 가리켜 "~하는 모습이 인상적임" / 처음보다 달라진 과정이 있으면 → "꾸준히 성장하는 모습을 보여 이후가 더욱 기대되는 학생임" / 태도가 두드러지면 → "~하는 태도가 돋보임" / 활동을 잘 해낸 결과가 핵심이면 → 평가 문장 없이 장면·결과로 맺음.
   - **무엇이 인상적인지 구체적으로 가리킨다**: "인상적임"만 단독으로 쓰지 않고, 앞에서 서술한 장면을 받아서 쓴다. (❌ "매우 인상적임" → ✅ "모르는 부분을 끝까지 질문해 스스로 해결하는 모습이 인상적임")
   - **넣을지 말지도 상황에 따라 정한다**: 근거가 약하면 넣지 않는다. 모든 세특이 평가 문장으로 끝날 필요는 없다.
   - **여러 학생을 한꺼번에 쓸 때**: 같은 맺음 문장이 반복되지 않게 학생마다 맺음 방식(장면 인용형·성장 기대형·태도형·평가 없이 결과로 맺음)을 섞고, 같은 표현이 두 번 이상 나오면 다시 쓴다.
   - **평가·맺음 표현은 아래 참고 목록에서 골라 써도 되고, 그 학생의 장면에 맞게 새로 만들어 써도 된다.** 목록은 예시이자 출발점이며, 어느 쪽이든 앞에서 서술한 장면에 맞아야 한다.
     | 종류 | 참고 목록 (앞에 구체 활동·장면이 와야 함) |
     |---|---|
     | 활동에 붙는 평가어 | 설득력 있는 / 우수한 / 짜임새 있는 / 체계적인 / 논리적인 / 완성도 높은 / 충실한 / 깊이 있는 / 정확한 / 명료한 / 꼼꼼한 + 발표·보고서·설명·풀이·분석·비평을 함·완성함·제공함 |
     | 장면 인상형 맺음 | ~하는 모습이 인상적임 / ~한 점이 눈에 띔 / ~하는 모습이 돋보임 / ~한 과정이 인상 깊음 / ~한 점이 두드러짐 |
     | 성장 기대형 맺음 | 앞으로의 성장이 더욱 기대되는 학생임 / 이후의 모습이 더욱 기대됨 / 꾸준히 발전하는 모습을 보여 앞으로가 기대됨 / 한 학기 동안 눈에 띄게 성장함 |
     | 태도형 맺음 | ~하는 태도가 돋보임 / ~하는 자세가 꾸준함 / 맡은 부분을 끝까지 책임지고 마무리함 / 모든 과정에 성실하게 임함 |
     - 목록에 딱 맞는 표현이 없으면 같은 어조로 새 표현을 만든다. (예: 발표였다면 발표의 어떤 점이 좋았는지, 질문이 많았다면 그 질문이 어떻게 이어졌는지를 받아서)
     - 같은 뜻이라도 학생마다 다른 말로 쓰고, 한 학생 안에서 같은 평가어를 두 번 쓰지 않는다. 여러 학생을 쓸 때는 목록 표현과 새 표현을 섞어 겹치지 않게 한다.
     - 근거가 약하면 평가·맺음 문장을 붙이지 않는다.
     - 역량 이름, 비유, 과장("탁월한 인재")은 쓰지 않는다.

`[수업 중 계기가 된 장면·의문] → [학생이 실제로 한 행동: 질문·자료 확인·계산을 말로] → [교사·또래와의 상호작용, 알게 된 점·확장] → [장면으로 맺거나, 상황에 맞는 교사 평가·기대 한 문장(11번)]`
좋은 예(발췌): "…읽기 자료에서 'dry'와 'mill'이 물리적 행위인데 왜 화학적 과정이라고 표현했는지 의문을 가짐. 영영사전으로 뜻을 확인하고 이차전지 제조 공정을 찾아 물리적 공정에도 화학적 방법이 쓰인다는 것을 확인함. 이후 교사의 권유로 과정을 정리해 발표했으며, 세부 공정에 대해 보충 설명을 제공함." → 역량 이름 없이 의문이 생긴 지점·확인 방법·발표 장면만으로 학업역량이 드러남.
