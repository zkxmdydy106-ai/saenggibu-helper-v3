# 출력 전 점검 체크리스트 (생기부)

생성 결과를 내보내기 **직전**에 모두 통과해야 한다. 하나라도 실패하면 고친 뒤 재점검.

## 1. 문체
- [ ] 모든 문장이 음슴체(`~함/~음/~임` 등)로 종결되는가?
- [ ] `~했다/합니다/입니다/이다` 등 평서·경어체가 섞이지 않았는가?
- [ ] 본문에 학생 이름·인칭 대명사를 불필요하게 반복하지 않았는가?

## 2. 글자수
- [ ] 영역 상한 이내인가? (과세특/자율 500자, 진로 700자)
- [ ] 상한의 90% 이상 채웠는가? (빈약하지 않게)
- [ ] 끝에 `(OOO자)` 표기했는가?

## 3. 금지사항 (forbidden.md 기준)
- [ ] 교외 수상·대회·공인어학시험·모의고사 성적이 없는가?
- [ ] 논문·도서출간·특허·해외활동이 없는가?
- [ ] 부모·가족 정보, 특정 대학/학원/강사명이 없는가?
- [ ] 학교 식별 정보(학교명·축제명 등)가 없는가?

## 4. 내용 품질
- [ ] 단순 활동 나열이 아니라 **질문·탐구·사고·변화**가 드러나는가?
- [ ] 추상적 미사여구 대신 **구체적 행동·근거**가 있는가?
- [ ] 교과·활동 내용과 학생의 사고가 **자연스럽게 연결**되는가?
- [ ] 입력에 없는 활동을 **창작하지 않았는가**? (없으면 보강 요청)

## 4-2. 사람이 쓴 느낌 (AI 티 제거)
- [ ] **실제 제목·자료명·수치·용어** 같은 구체 알맹이가 있는가? (없으면 교사에게 요청)
- [ ] 종결어미와 문장 길이가 **다양**한가? (`~함`만 반복하지 않음)
- [ ] "인상적임/돋보임" 등 평가어가 **구체 묘사 뒤에** 붙는가? (붕 뜨지 않음)
- [ ] "후속 탐구를 계획함/과제를 남김/~할 것으로 보임" 같은 **정형 마무리**가 없는가?
- [ ] "~하지 못해 아쉬움" 같은 **부정·한계 지적**이 없는가?
- [ ] **비유·은유·현학적 표현**이 없는가? ("밀고 나가는 힘", "함께 바라봄", "촘촘히 잇는 모습", "선을 긋는 눈" 등 → 담백한 사실 서술로)
- [ ] 지어낸 **감정·의욕 서술**이 없는가? ("~하고 싶어 함", "흥미로워함", "받아들임" → 실제 한 절차·근거로)
- [ ] 맺음이 **구체 장면·사실**이거나, 필요할 때만 태도·변화를 관찰한 교사 판단 한 문장인가?

## 4-3. 수업 장면·학업역량 (2026-09 추가)
- [ ] 역량 이름("문제해결력", "사고력", "탐구역량", "~힘을 보임", "~감각을 보임")을 쓰지 않았는가? ("설득력 있는 ~를 함", "우수한 ~를 함"처럼 활동에 붙는 평가어는 허용)
- [ ] 수업 중 **구체 장면**(의문이 생긴 지점, 질문, 피드백 반영, 발표·또래 설명)이 1개 이상 있는가?
- [ ] 학업태도·탐구력·학업성취 중 2개 이상이 **장면 속 행동으로** 드러나는가?
- [ ] 수식·기호(`f(x)=`, `x²`, `∑`, `√`, 계산식)를 쓰지 않고 말로 풀었는가?
- [ ] 입력에 없는 동기·장면을 지어내지 않았는가?
- [ ] 들어온 자료(교사 관찰, 활동 산출물, 성적 추이, 이전 생기부)를 모두 참고했는가? 교사 관찰이 있으면 그것이 문장의 뼈대인가?
- [ ] 성적 추이를 참고했더라도 점수·등급·석차 수치가 본문에 없는가?
- [ ] 이전 학기 생기부와 같은 문장·소재를 반복하지 않고, 이어지는 흐름을 보여주는가?
- [ ] 교사 맺음 문장("~모습이 인상적임", "더욱 기대되는 학생임")을 썼다면, 앞에서 서술한 장면에 근거하는가? 그 학생의 상황(눈에 띈 장면·성장·태도)에 맞는 방식인가?
- [ ] 여러 학생을 쓸 때 같은 맺음 문장이 반복되지 않는가?
- [ ] 평가·맺음 표현이 참고 목록에서 골랐든 새로 만들었든 이 학생의 장면에 맞는가? 한 학생 안에서 같은 평가어가 두 번 나오지 않는가?

## 4-4. 모범 세특 구성 (2026-09-28 추가)
- [ ] 대표 산출물 1개 + 확장 1개 중심으로, 한 흐름으로 이어지는가? (작은 장면을 5개 이상 이어 붙이지 않았는가?)
- [ ] 교과 개념어가 정확히 여러 개 들어갔는가? (쉬운 말로만 쓰지 않았는가?)
- [ ] 여러 학생을 쓸 때 구조·순서·핵심 단어가 서로 다르고, 각 학생이 다르게 한 부분이 중심인가?
- [ ] 틀을 채우려고 입력에 없는 수치·도구·이전 활동을 만들지 않았는가?
