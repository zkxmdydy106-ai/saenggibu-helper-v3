# 수행평가 채점 스킬 (assessment-grader)

학생 제출물을 **채점기준표(루브릭)** 에 맞춰 채점한다.
핵심 철학: **점수는 기준표에 근거하고, 근거는 제출물에 근거한다. 인상이 아니라 증거로 채점한다.**

## 언제 쓰나
- Google Classroom 과제의 학생 제출물을 일괄 채점할 때
- Classroom 밖에서 직접 받은 이미지/한글/Word/PDF/PPT 제출물을 채점할 때
- 채점기준표에 맞춰 학생별 점수·근거·피드백과 엑셀 결과가 필요할 때

## 채점 절차 (반드시 순서대로)
1. **대상 확보** — Classroom 과제 제출물 수집 또는 업로드 파일 접수. 학생 식별(이름/학번) 확인.
2. **채점기준표 요청** ★ — 기준표가 없으면 먼저 요청한다(파일/Classroom·Drive 위치/텍스트). 받기 전엔 채점하지 않는다. → `references/rubric-intake.md`
3. **기준표 정규화** — 평가요소·만점·가중치·수준별 기술·총점을 구조화. 배점 합 검증.
4. **제출물 분석** — 모든 형식(이미지·hwp·docx·pdf·pptx) 텍스트/내용 추출. → `references/file-extraction.md`
5. **채점** — 요소별 증거 추출 → 수준 대조 → 점수 → 근거 2~3줄 → 균형 피드백(강점+보완). → `references/scoring-method.md`
6. **검증** — 만점 초과·합계·근거 누락·일관성 자가 점검(`../../hooks/grading_guard.py`).
7. **엑셀 산출** — 3개 시트 워크북 생성. → `references/excel-output.md`, `scripts/build_scoresheet.py`

## 절대 규칙 (요약)
- 채점기준표 없이 채점하지 않는다.
- 모든 점수에 제출물 기반 **구체 근거** 필수.
- 요소 점수 ≤ 만점, 총점 = 가중 합. 산술 오류 0.
- 제출물에 없는 내용 창작 금지. 비면 ‘근거 부재’ 명시.
- 필체·이름·성별 등 무관 요소로 점수 조정 금지.
- 표절·AI 의심은 단정 말고 ‘확인 권장’ 플래그만.
- 결과는 1차 초안 — 최종 확정은 교사.

## 피드백 톤 (균형)
- 강점 1~2개 + 보완점 1~2개 + 다음 행동 제안.
- 학생이 읽을 수 있는 존중하는 표현. 비난·인신공격·낙인 금지.
- 점수의 이유를 기준표 문구와 연결해 설명.

## 산출물
- 채팅: 학생별 요약 표 + 점검 요약 + 1차 초안 고지.
- 엑셀: ① 채점결과(기준별 점수 분해) ② 근거·피드백 ③ 요약 통계.
