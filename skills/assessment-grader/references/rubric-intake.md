# 채점기준표(루브릭) 인테이크

채점기준표는 채점의 **유일한 근거**다. 받기 전에는 채점하지 않는다.

## 1. 요청 방법 (한 번만, 간결하게)
> 이 과제의 **채점기준표(루브릭)** 를 주세요. 다음 중 편한 방식이면 됩니다.
> 1. 파일 업로드 — 엑셀/한글/Word/PDF/이미지 모두 가능
> 2. Classroom 과제에 연결된 기준표 또는 Drive 파일 위치 알려주기
> 3. 텍스트로 붙여넣기 — 평가요소 · 배점 · 수준별 기술 포함

교사가 "기준표 없음/알아서 해줘"라고 하면, 채점을 강행하지 말고 **임시 기준표 초안을 제안**해 승인받은 뒤 채점한다(과제 성격에 맞는 표준 요소 제시 → 교사 확정).

## 2. 정규화 구조
받은 기준표를 아래 JSON 형태로 내부 정리한다(`build_scoresheet.py` 입력과 호환).

```json
{
  "assignment": "독서 감상문",
  "scale": "점수제",
  "total": 20,
  "criteria": [
    {"name": "내용 충실성", "max": 8, "weight": 1,
     "levels": [
       {"band": "상", "range": "7-8", "desc": "주제를 깊이 있게 다루고 근거가 충분함"},
       {"band": "중", "range": "4-6", "desc": "주제를 다루나 근거가 부분적임"},
       {"band": "하", "range": "0-3", "desc": "주제 이해가 부족하거나 근거 없음"}
     ]},
    {"name": "논리 구성", "max": 7, "weight": 1, "levels": [ ... ]},
    {"name": "표현·형식", "max": 5, "weight": 1, "levels": [ ... ]}
  ]
}
```

## 3. 검증 체크
- 요소 만점(×가중치) 합 == total 인가? 다르면 교사에게 1회 확인.
- 수준 구간이 겹치거나 비어 있지 않은가?
- 등급제(A/B/C·수우미양가)면 등급→점수 환산 규칙을 확인.
- 체크리스트형(핵심요소 유무)이면 각 항목 배점을 확인.

## 4. 모호할 때
- 수준 기술이 없으면(배점만 있음): 상/중/하 구간을 균등 가정하고 그 가정을 한 줄로 고지.
- 가중치 미표기: 1로 가정.
- 표·이미지·한글 형태의 기준표: `file-extraction.md` 절차로 읽어 구조화.

모든 가정은 결과에 한 줄로 명시한다. 추측으로 기준 자체를 바꾸지 않는다.
