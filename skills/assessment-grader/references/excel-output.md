# 엑셀 출력 구조

`scripts/build_scoresheet.py`에 채점 결과 JSON을 넘겨 표준 워크북을 생성한다.
파일명: `수행평가_채점결과_<과제명>_<YYYYMMDD>.xlsx`

## 시트 1 — 채점결과 (기준별 점수 분해)
행 = 학생, 열:

`학번 | 이름 | <요소1>(/만점) | <요소2>(/만점) | … | 총점(/총점) | 등급 | 확인필요`

- 요소 열 머리글에 만점 표기(예: `내용 충실성 /8`).
- 총점 셀 강조(굵게/색). 미제출은 '미제출', 판독불가는 '확인필요'.
- 헤더 행 고정, 열 너비 자동.

## 시트 2 — 근거·피드백
행 = 학생 × 요소(또는 학생 1행에 요약), 열:

`이름 | 평가요소 | 부여점수/만점 | 근거 | 피드백`

- 근거: 제출물 기반 2~3줄. 피드백: 강점+보완+제안(균형 톤).
- 셀 자동 줄바꿈, 상단 정렬.

## 시트 3 — 요약 통계
- 학급 인원/제출/미제출/확인필요 수
- 총점 평균·최고·최저·중앙값·표준편차
- **요소별 평균 점수**(어느 기준이 약한지 진단)
- 점수 분포(구간별 인원) — 가능하면 막대 차트
- 등급 분포(등급제일 때)

## 입력 JSON 스키마 (build_scoresheet.py)
```json
{
  "assignment": "독서 감상문",
  "date": "2026-06-25",
  "total": 20,
  "criteria": [
    {"name": "내용 충실성", "max": 8},
    {"name": "논리 구성", "max": 7},
    {"name": "표현·형식", "max": 5}
  ],
  "students": [
    {
      "id": "10301", "name": "김OO", "status": "제출",
      "scores": {"내용 충실성": 7, "논리 구성": 5, "표현·형식": 4},
      "evidence": {"내용 충실성": "주제를 ...", "논리 구성": "...", "표현·형식": "..."},
      "feedback": {"내용 충실성": "강점 ... 보완 ...", "논리 구성": "...", "표현·형식": "..."},
      "grade": "B", "flag": ""
    }
  ]
}
```
- `status`: 제출 / 미제출 / 확인필요
- `grade`, `flag`(예: 표절 확인 권장)는 선택.
- 총점은 스크립트가 자동 합산·검산(불일치 시 경고).
