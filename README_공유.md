# 공유 안내 — 교사 업무 보조(생기부 작성 + 수행평가 채점)

이 폴더는 다른 선생님이 같은 방식으로 쓰도록 만든 **시스템 파일 모음**입니다. 학생 개인정보 보호를 위해 **생성된 채점 결과·세특 등 학생 산출물은 포함하지 않았습니다.**

## 포함된 것
- `프로젝트지침.md` — 라우터 + 공통 원칙(Project Instructions용)
- `00_지침_붙여넣기용.md` — 폴더 연결 방식에서 프로젝트 지침에 붙여넣을 글
- `프로젝트지침_생기부.md` — 생기부 모드 상세: 작업 절차, 목표 결과물(모범 세특), 문장 규칙, 출력 형식
- `skills/saenggibu-writer/` — 생기부(세특) 작성 규칙·예시·체크리스트
- `skills/assessment-grader/` — 수행평가 채점 규칙·엑셀 생성 스크립트
- `hooks/` — 형식가드(생기부)·채점가드 + 설명 문서
- `harness/` — 품질 평가표·회귀 테스트
- `examples/`, `일괄입력_템플릿.csv`

## 받은 선생님이 쓰는 방법 (셋 중 하나)

### 방법 1. 폴더를 Claude에 연결해서 쓰기 — 가장 간단, 권장
1. 이 `생기부생성기` 폴더를 내 컴퓨터에 둔다.
2. Claude 데스크톱 앱에서 이 폴더(또는 이 폴더가 들어 있는 상위 폴더)를 작업 폴더로 연결한다.
3. 첫 요청을 이렇게 시작한다:
   > 생기부생성기 폴더의 `프로젝트지침.md`와 `프로젝트지침_생기부.md`를 먼저 읽고, 그 규칙대로 아래 학생의 [과목] 세특을 써줘.
   > (교사 관찰 / 학생 활동·산출물 또는 링크 / 성적 추이 / 이전 학기 생기부 — 있는 것만)
4. 이 방식이면 Claude가 폴더 안의 점검 스크립트(`hooks/format_guard.py`)까지 직접 돌려 수식·글자수·음슴체를 확인한다.

### 방법 1-2. 폴더 연결 + 프로젝트 지침만 넣기 (지식 파일 업로드 불필요)
1. 압축을 푼 폴더를 Claude 프로젝트의 작업 폴더로 연결한다(데스크톱 앱).
2. `00_지침_붙여넣기용.md`를 열어 **전체 선택(Ctrl+A) → 복사 → 프로젝트 지침에 붙여넣기** 한다.
3. 이후에는 "○○ 학생 세특 써줘"처럼 바로 요청하면 된다. 규칙 파일을 고쳐도 다시 올릴 필요 없이 바로 반영된다.

### 방법 2. Claude 프로젝트(웹·앱)로 쓰기
1. 새 프로젝트를 만든다.
2. `프로젝트지침.md` 내용을 프로젝트 지침(Instructions)에 붙여넣는다.
3. 아래 파일을 프로젝트 지식(Knowledge)으로 올린다.
   - `프로젝트지침_생기부.md` ← 가장 중요(목표 결과물·절차·규칙이 다 들어 있음)
   - `skills/saenggibu-writer/SKILL.md`, `references/checklist.md`, `references/examples.md`, `references/forbidden.md`
   - (선택) `hooks/format_guard.py`, `harness/EVAL_CHECKLIST.md`
   - (수행평가 채점도 쓸 때) `skills/assessment-grader/` 안의 파일들
4. 규칙 파일을 고치면 프로젝트에 올린 사본은 자동으로 바뀌지 않으니, 고친 파일을 다시 올린다.

### 방법 3. Claude Code
이 폴더를 저장소로 두고 `프로젝트지침.md`를 `CLAUDE.md`로, `skills/`를 `.claude/skills/`로, `format_guard.py`·`grading_guard.py`를 `.claude/hooks/`로 옮기고, HOOK 문서의 settings 스니펫을 `.claude/settings.json`에 병합한다.

## 받은 뒤 제대로 되는지 확인하기
`프로젝트지침_생기부.md` 1장의 입력(교사 메모 + 수행평가 내용)을 그대로 넣어 세특을 요청해 본다. 1장의 모범 세특과 **같은 방식**(실제 제목, 수식 없이 말로 풀기, 역량 이름 없이 행동으로, 장면에 맞는 맺음, 500자 이내)으로 나오면 설치가 잘 된 것이다. 문장이 똑같을 필요는 없다.

## 공유할 때 주의
- 학생 실명·학번이 들어간 파일(관찰 기록, 성적표, 생성된 세특)은 이 폴더에 넣어 공유하지 않는다. `examples/`의 샘플은 가상의 이름이다.
- `프로젝트지침_수행평가채점.md`는 아직 없다. 채점 모드는 `skills/assessment-grader/SKILL.md`만으로 동작한다.
